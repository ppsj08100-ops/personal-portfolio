# BEYOND THE SURFACE

## DEEPER 포트폴리오 챗봇

오른쪽 아래 `ASK DEEPER` 버블에서 대표 작업, 딥디크 기여 내용, 사용 도구, 소개와 연락 방법을 질문할 수 있습니다. 추천 질문과 직접 입력을 모두 지원하며 답변의 링크는 사이트 내 해당 작업으로 이동합니다. 이 안내 기능은 API 키 없이 동작합니다.

자유로운 AI 대화는 `api/chat.js`에서 AI SDK와 Vercel AI Gateway를 통해 스트리밍합니다. 현재 키가 없으면 연결 전임을 알리고 포트폴리오 안내를 계속 제공합니다. 모델 답변이나 문의 전송 성공을 흉내 내지 않습니다.

AI를 연결하려면 `.env.example`을 `.env.local`로 복사하고 `AI_GATEWAY_API_KEY`를 설정한 뒤 개발 서버를 다시 시작합니다. 선택 항목 `AI_GATEWAY_MODEL`로 모델을 바꿀 수 있습니다. 키에는 `VITE_` 접두사를 붙이지 마세요. Vite 개발·프리뷰 서버에서는 같은 `/api/chat` 엔드포인트를 사용하며, Vercel 배포 시 프로젝트 환경 변수에 서버 키를 등록합니다. 정적 파일만 호스팅하는 환경에서는 기본 안내 기능만 동작합니다. 키 발급은 [Vercel AI Gateway 설정 문서](https://vercel.com/docs/ai-gateway/getting-started)를 참고하세요.

사이트 정보와 기본 답변은 `src/portfolio-chat-knowledge.js`, 화면과 동작은 `src/portfolio-chat.js`와 `src/portfolio-chat.css`에서 수정할 수 있습니다. 대화는 현재 열린 페이지 메모리에만 유지하며 브라우저 저장소에 기록하지 않습니다.

**박서진 · Park Seojin | UI/UX · Web · Visual Design Portfolio**

화면에 보이는 결과와 그 뒤의 생각을 함께 소개하는 개인 포트폴리오입니다. 디자인 기획, 사용자 조사, 화면 설계, 웹 구현, 영상 작업을 하나의 스크롤 경험으로 연결합니다.

바다의 수면에서 깊은 곳으로 내려가는 흐름을 따라 작업 방식과 프로젝트를 만나도록 구성했습니다. 별빛과 수면, 해양 생물, 난파선, 기포 등의 시각 요소에 스크롤 애니메이션과 인터랙션을 더했습니다.

## 프로젝트와 콘텐츠

### DIPTYQUE — 브랜드 웹 리뉴얼 팀 프로젝트

딥디크의 향과 이야기를 에디토리얼 레이아웃과 웹 인터랙션으로 풀어낸 작업입니다. 완성 화면과 함께 그 화면이 만들어진 과정을 소개합니다.

- **결과물:** 01 프로젝트 개요, 02 메인 홈페이지의 브랜드 경험과 제품 탐색, 03 홈페이지의 타이포그래피와 모션, 04 GALERIE, 05 BRAND HISTORY, 06 FOR THE PLANET을 소개합니다. 직접 담당한 Fragrances Story는 별도의 07 MY CONTRIBUTION에서 소개합니다.
- **인트로 목업:** 모니터와 휴대폰 안에서 실제 데스크톱·모바일 사이트가 첫 화면부터 하단까지 내려갑니다. 보이는 동안 음소거로 반복 재생하고 공통 재생·일시정지 버튼으로 두 화면을 함께 제어합니다. 다른 전시로 이동하거나 탭을 숨기면 멈추며, 모션 감소 설정에서는 직접 재생할 수 있습니다.
- **프로젝트 개요 목업:** 큰 모니터는 실제 사이트의 첫 인트로 영상 바로 아래에서 시작해 전체 페이지 하단까지 내려가는 65초 영상입니다. 작은 모니터는 오르페옹·34번가·플레르 드 뽀의 향 스토리만 전환되는 28초 영상으로 구성했습니다. 모니터 안을 같은 8:5 비율로 채우고, 큰 모니터의 재생·일시정지 버튼으로 두 화면을 함께 제어합니다. 다른 전시로 이동하거나 화면 밖으로 나가면 함께 멈추고 모션 감소에서는 직접 재생할 수 있습니다. WEBSITE·PROPOSAL 링크는 각 상세 설명 아래에 왼쪽 정렬로 배치합니다.
- **02 브랜드 경험 목업:** 큰 화면은 메인 홈페이지의 브랜드 콘텐츠 → 모닝·이브닝 리추얼 → 카테고리·향 발견의 44초 흐름을, 작은 화면은 실제 SHOP에서 향수와 캔들을 스크롤·호버·카테고리 전환으로 탐색하는 영상을 보여줍니다. 큰 화면의 공통 버튼으로 두 영상을 함께 제어합니다.
- **03 타이포그래피와 모션 목업:** 메인 홈페이지에서 “Every scent begins as a memory” 문장이 스크롤에 맞춰 선명해지고 식물 드로잉으로 이어지는 12초 영상입니다. 향수 이야기 서브페이지의 챕터·콜라주·향 노트 영상은 포함하지 않습니다.
- **04 갤러리 목업:** 실제 `/galerie`를 처음부터 푸터까지 내려가는 38초 영상입니다. 네 가지 향의 풍경, 향 설명과 관련 제품, Another 탐색을 보여줍니다.
- **05 히스토리 목업:** 실제 `/about/history`의 첫 문장에서 패브릭·오브제·캔들·메종까지 이어지는 40초 영상입니다. 기업정보 푸터 직전의 식물·바다·태양 장면에서 마무리합니다.
- **06 환경 철학 목업:** 실제 `/about/for-the-planet`의 아치 확장, 가로 콜라주, 숲의 다람쥐 클릭, 환경·사회적 약속, 푸터까지 담은 39.2초 영상입니다. 세 서브페이지 영상은 1280×800 비율로 모니터를 채우며 개별 재생·일시정지, 화면 밖 정지, 모션 감소 시 수동 재생을 지원합니다. 각 WEBSITE 링크는 해당 서브페이지로 연결합니다.
- **참여 과정:** 담당 작업 소개와 팀 협업 내용
- **Intro–08·CANVAS–SCREENS 목업 거품:** 두 전시 전체에 3–8.5px의 작은 상승 거품을 표시합니다. 기기 양옆의 가는 테두리와 하이라이트를 살리고, 30–46초 주기로 천천히 올라오게 해 문서를 가리지 않으면서도 보이게 했습니다. 비활성 페이지·숨겨진 목업·탭 숨김·열린 대화상자에서는 정지합니다. 장식용 보조 목업도 활성 페이지에서는 정상적으로 움직이며, 모션 감소에서는 거품을 같은 위치에 정지시킵니다.
- **기획 자료:** 린 캔버스, 시장·브랜드 조사, 사용자 인터뷰와 분석, 문제 정의, 메뉴트리와 구조 설계, 무드보드, 와이어프레임과 UI 컴포넌트
- **01 린캔버스:** [지정한 Figma의 세 원본](https://www.figma.com/design/srssqZHNPbxBDzXAwby1u6/DIPTYQUE-renewal-project?node-id=3131-19446)을 공식 채널·브랜드 경험·향 탐색으로 나눠 보여줍니다. 2200×1650 원본은 큰 화면 하나와 같은 크기의 보조 화면 두 개로 배치합니다. PC에서는 큰 화면 옆에 두 보조 화면을 세로로 정렬하고, 모바일에서는 큰 화면 아래에 나란히 배치합니다. 세 화면 모두 같은 4:3 비율과 얇은 프레임을 사용하며 서로 가리지 않습니다. 선택 버튼으로 큰 화면·보조 화면·목업 캡션·해당 Figma 링크를 바꿉니다. 크게 보기에서도 세 자료 전환, 화면 맞춤·원본 크기, 원본 이미지 열기를 지원하며 수치가 프로토타입 검증 목표라는 안내를 제공합니다.
- **기획 전시 텍스트:** 01 CANVAS–07 SCREENS의 설명 영역은 03 USER RESEARCH처럼 번호, 두 줄 영문 제목, 한국어 핵심 문장, 짧은 본문, 자료 탭, 하단 PROPOSAL 링크 순서로 통일합니다. 반복되는 부제·태그·추가 인사이트와 항목 나열은 설명 영역에서 덜어냈습니다. 선택 자료의 세부 설명과 린캔버스 검증 목표 안내는 크게 보기 안에서 제공하고, 04의 사용자 자료 선택과 05의 사용자별 플로우 선택은 확대 보기 안에 배치합니다. 원본 자료와 자료 전환 기능은 유지합니다.
- **Intro–08 타이포그래피:** 기획 전시와 같은 Julius 영문 제목·Pretendard 한국어 요약·본문 위계를 사용합니다. 제목과 본문의 크기·굵기·자간·행간·단락 간격을 PC·작은 노트북·모바일에서 맞추며, 긴 구분선 대신 여백으로 정보를 구분합니다. 설명과 프로젝트 정보·링크·인터랙션은 유지합니다.
- **02 조사 자료 목업:** 작은 보조 모니터를 제거하고 한 개의 큰 화면에서 자사·경쟁사·STEEP·3C 자료를 전환합니다. 원본 크게 보기와 자료 탭을 유지합니다.
- **03 사용자 조사 목업:** PC에서는 큰 설문 결과 화면 옆에 보조 자료 두 장을 한 열로 정렬하고, 묶음과 캡션을 설명 영역에 맞춰 아래로 내립니다. 화면 높이에 맞춰 세 목업을 함께 줄이고, 모바일에서는 큰 결과 아래에 보조 화면의 높이를 맞춰 나란히 배치합니다. 인터뷰 탭에서는 하나의 큰 화면으로 전환합니다. 세 번째 설문의 보조 미리보기는 회색 캡처 여백을 정리하고 응답 요약·의견 영역을 화면에 맞춰 표시합니다. 원본 이미지와 확대 자료는 유지하며, 크게 보기에서 설문 자료 전환과 화면 맞춤·원본 크기·원본 열기를 지원합니다.
- **04 UX 전략 목업:** 퍼소나·저니맵·린캔버스 탭마다 같은 종류의 세 사용자 자료가 한꺼번에 표시됩니다. 큰 화면과 보조 화면 두 개로 세 자료를 함께 보여주며, 사용자별 원본 선택과 확대는 대화상자 안에서 지원합니다.
- **05 구조 설계 자료:** 메뉴트리와 요구사항 정의서는 각각 중앙의 큰 모니터 하나로, 사용자 플로우차트는 Figma 원본 3종을 함께 표시합니다. 요구사항 화면에 관련 없는 메뉴트리 보조 목업을 표시하지 않습니다. 바깥의 사용자 선택은 없애고 확대창에서 원본별로 선택할 수 있게 했습니다. 각 원본의 전체 내용과 비율을 유지하며, PC 목업·캡션을 함께 아래로 내려 설명 영역과 높이를 맞춥니다.

### DIESEL / REPETTO — 개인 웹사이트 리디자인

두 브랜드의 서로 다른 시각적 성격을 바탕으로 **Figma 메인 페이지 UI 디자인부터 웹사이트 구현·배포까지 진행한 개인 작업**입니다. 전체 화면 크기의 PERSONAL PROJECTS 도입부 뒤에서 Diesel과 Repetto를 각각 한 페이지로 만나며, 하나의 공통 스테이지 안에서 옆으로 전환합니다.

전시 배경은 바다에 잠긴 선장의 개인 작업실입니다. 선미 창 너머의 바닷물과 목재 선체, 한 개의 의자와 넓은 해도 책상을 유지하면서, 부드러운 가구 곡선과 작은 조개·자개 장식, 물속에 떠 있는 얇은 커튼으로 우아한 분위기를 더했습니다. PC·모바일에 각각 맞는 구도를 사용하며 배경만 짙은 남색·청회색·은청색으로 조정해 사이트의 일러스트와 연결합니다. 두 작업은 실제 배포 사이트의 인트로부터 푸터까지 내려가는 **1920×1080 스크롤 영상**으로 소개하며, 같은 16:9 모니터 프레임을 여백 없이 채웁니다. 왼쪽에는 작은 번호 라벨, 브랜드명, 두 줄 핵심 문장, 간결한 본문과 작업 범위를 배치합니다. 제목·요약·본문의 글자 크기·굵기·자간·행간은 딥디크 팀 전시와 같고, 사이트 바로가기는 둥근 버튼으로 제공합니다. 작은 화면에서는 제목 → 영상 → 설명·작업 범위 → 사이트 바로가기 순서를 사용합니다.

| 작업 | 소개 범위 |
| --- | --- |
| **DIESEL** | 강한 대비와 대형 타이포그래피를 사용한 실제 사이트의 인트로 → 전체 콘텐츠 → 푸터를 16:9 스크롤 영상으로 보여줍니다. 화면 높이에 맞춰 데스크톱 기준 최대 900px 모니터에 표시합니다. |

- **영상 설명 타이포그래피:** 딥디크·디젤·레페토와 같은 작은 번호 라벨, 가벼운 제목, 두 줄 핵심 문장, 짧은 본문으로 정리합니다. 영문 제목·요약·본문의 글자 크기와 간격을 통일하고, 한글 작품명은 화면 폭에 맞춰 가벼운 굵기로 표시합니다. 재생 시간·포맷은 긴 구분선 없이 배치하며, 디젤의 상세 기획 내용은 둥근 ‘영상 기획 자세히’ 버튼에서 열 수 있습니다. 영상 원본 비율·재생 조작·작품 전환은 유지합니다.

## 로컬에서 실행하기

### 1. 준비

- **Node.js 22.12.0 이상**과 npm을 설치합니다. 현재 Vite의 전체 Node.js 지원 범위는 `^20.19.0 || >=22.12.0`입니다.
- 저장소를 복제하려면 Git이 필요합니다.
- 현재 프런트엔드를 실행하거나 빌드하는 데 별도 환경변수나 API 키는 필요하지 않습니다.

### 2. 저장소 복제

```bash
git clone https://github.com/ppsj08100-ops/personal-portfolio.git
cd personal-portfolio
```

이미 프로젝트를 내려받았다면 해당 폴더를 터미널에서 열고 다음 단계부터 진행합니다. 아래 명령은 모두 `package.json`이 있는 **프로젝트 최상위 폴더**에서 실행합니다.

### 3. 의존성 설치와 개발 서버 실행

```bash
npm ci
npm run dev
```

`npm ci`는 `package-lock.json`에 기록된 버전에 맞춰 의존성을 설치합니다. 서버가 시작되면 터미널의 `Local` 주소를 브라우저에서 여세요. 기본 주소는 `http://localhost:5173`이며, 해당 포트가 사용 중이면 다른 포트가 표시될 수 있습니다.

코드를 저장하면 개발 서버가 변경 내용을 반영합니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

## 빌드 결과 확인하기

```bash
npm run build
npm run preview
```

빌드가 성공하면 `dist/`에 배포용 파일이 생성됩니다. `npm run preview`가 표시하는 주소에서 개발 소스가 아닌 **실제 빌드 결과**를 확인할 수 있습니다. 기본 미리보기 주소는 `http://localhost:4173`입니다.

| 명령 | 용도 |
| --- | --- |
| `npm ci` | 잠금 파일을 기준으로 의존성 설치 |
| `npm run dev` | 수정 내용을 확인하는 개발 서버 실행 |
| `npm run build` | `dist/`에 배포용 결과물 생성 |
| `npm run preview` | 생성된 `dist/`를 로컬에서 미리보기 |

빌드 성공은 코드와 자산을 묶을 수 있다는 확인입니다. 배포 전에는 메뉴, 프로젝트 상세 보기, 영상, 갤러리와 모바일 화면도 브라우저에서 확인하세요.

└── src/
    ├── main.js                 # CSS 로드와 섹션별 기능 초기화
    ├── style.css               # 기본 스타일

### 이미지와 영상을 바꿀 때

`public/` 안의 파일은 코드에서 `public`을 제외한 경로로 참조합니다.

```html
<!-- 실제 파일: public/images/profile/moment-film-poster.jpg -->
<img src="/images/profile/moment-film-poster.jpg" alt="개인 영상의 포스터" />
```

파일을 교체하거나 이름을 바꾸면 HTML, CSS 또는 JavaScript에서 사용하는 경로도 함께 수정하세요. 영상은 파일 경로뿐 아니라 포스터 이미지와 `<source>`의 형식도 확인해야 합니다. 배포 환경에서 누락되지 않도록 파일명 대소문자를 정확히 맞춥니다.

디자인 의도를 확인할 때는 [design-guideline.md](design-guideline.md)를, 실제 적용 값을 바꿀 때는 공통 토큰과 섹션별 스타일을 함께 참고하세요.

## 정적 사이트로 배포하기

이 프로젝트는 Vite로 빌드한 정적 파일을 호스팅하는 방식입니다. Vercel 등의 호스팅 서비스에서 사용할 기본 값은 다음과 같습니다.

| 항목 | 값 |
| --- | --- |
| 프로젝트 루트 | `package.json`이 있는 저장소 최상위 폴더 |
| 프레임워크 프리셋 | Vite |
| 설치 명령 | `npm ci` |
| 빌드 명령 | `npm run build` |
| 배포할 출력 폴더 | `dist` |

현재 이미지·영상·폰트 경로는 사이트 루트(`/`)를 기준으로 작성되어 있습니다. `/personal-portfolio/`와 같은 하위 경로에 배포하려면 Vite의 기본 경로 설정과 코드의 정적 자산 경로를 함께 점검해야 합니다.

`dist/`는 빌드로 다시 생성할 수 있어 Git 추적에서 제외합니다. `.env*`, `node_modules/`, `.vercel/`, `artifacts/`, `output/`도 [.gitignore](.gitignore)에 따라 제외하며, 사이트에 사용하는 이미지·영상은 `public/`에 보관합니다.

| `npm` 또는 `node` 명령을 찾을 수 없음 | Node.js와 npm 설치 여부를 확인하고 터미널을 다시 엽니다. |
| 설치·빌드 중 Node 버전 관련 오류 | `node -v`로 버전을 확인하고 위의 Vite 지원 범위에 맞춥니다. |
| `package.json`을 찾을 수 없음 | `src/`나 이미지 폴더가 아닌 프로젝트 최상위에서 명령을 실행했는지 확인합니다. |
| HTML 파일을 직접 열었을 때 화면이 정상적으로 나오지 않음 | `npm run dev` 또는 빌드 후 `npm run preview`로 실행합니다. |
| 배포 후 이미지·영상이 보이지 않음 | 파일이 Git에 포함됐는지, 경로와 대소문자가 맞는지, 사이트가 루트 경로에 배포됐는지 확인합니다. |
| 갤러리가 입체 화면 대신 가로 목록으로 보임 | 화면 크기, 모션 감소 설정, WebGL 지원에 따른 대체 표시일 수 있습니다. |
| 영상이나 사운드가 자동으로 시작되지 않음 | 브라우저 재생 정책과 모션 설정을 확인합니다. 사운드는 `SOUND`를 눌러 켜야 합니다. |

## 현재 구현 범위

- **문의 폼:** 필수 입력값을 검사하고, 실제로 전송되지 않았다는 안내를 표시합니다. 문의를 저장하거나 이메일로 발송하는 서버는 연결되어 있지 않습니다.
- **하단 연락처:** `src/footer-content.js`의 이메일과 SNS 주소는 현재 등록 예정 상태입니다. 실제 주소를 넣으면 해당 데이터에 맞춰 표시됩니다.
- **개인 웹사이트 리디자인:** DIESEL과 REPETTO는 Figma 메인 페이지 UI 디자인과 웹사이트 구현·배포를 진행한 작업입니다. 브랜드별 디자인 의도와 콘텐츠 흐름을 두 문단으로 설명하고 짧은 작업 범위를 표시합니다. 실제 배포 사이트의 인트로부터 푸터까지 담은 16:9 스크롤 영상이 모니터를 채우며, 현재 선택한 작품이 보일 때만 재생됩니다. 가로 전환, 인라인 영상 조작, 모션 감소용 포스터와 직접 재생, 배포 사이트 링크를 제공합니다.
